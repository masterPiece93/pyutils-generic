## [0.1.0] - 2026-09-09

### Added
- Initial public release on PyPI under the distribution name `pyutils_generic`.
- `pyutils_generic.colored` — ANSI terminal styling (`Palette`, `Effects`, `Styleit`, `cprint`).
- `pyutils_generic.immutables` — `ReadOnlyMeta`, `ReadOnlyDictWrapper`, `imdict`.
- `pyutils_generic.typecheck` — `strict` decorator, `TypeCheck`, `CoercedType`, custom types registry.
- `pyutils_generic.schema` — `JsonDictValidator` for lightweight JSON dict validation.
- `py.typed` marker for PEP 561 typing support.

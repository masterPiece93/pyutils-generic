# Security Policy

## Supported Versions

Only the latest released minor version of `pyutils_generic` receives security
fixes.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, use GitHub's private vulnerability reporting:

- <https://github.com/masterPiece93/pyutils-generic/security/advisories/new>

Or email the maintainer directly at **ankit8290@gmail.com** with:

- A description of the issue and its impact.
- Steps to reproduce (a minimal proof-of-concept is ideal).
- Any suggested mitigation, if you have one.

You will receive an acknowledgement within **7 days**. Once the report is
triaged, we will keep you informed of the fix and coordinated disclosure
timeline.
